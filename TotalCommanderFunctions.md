# Total Commander - Comprehensive Feature Analysis

## Overview
Total Commander is a popular file manager for Windows with extensive functionality. This document catalogs its key features for comparison with our Midnight Commander .NET implementation.

## Core File Management Features

### 1. **Dual Panel Interface**
- Two file panels (left/right) with independent navigation
- Tabbed interface within each panel
- Synchronized directory navigation
- Customizable panel layouts

### 2. **File Operations**
- **Copy/Move/Delete/Rename** with progress tracking
- **Multi-rename tool** with advanced pattern matching
- **Synchronize directories** with preview
- **File splitting/joining** for large files
- **File properties** with detailed attributes
- **Custom copy** with verification

### 3. **Advanced File Operations**
- **Multi-rename tool** with regex support
- **File property editing** (timestamps, attributes)
- **File splitting/joining** for large files
- **File content comparison** (text and binary)
- **CRC32/MD5/SHA checksums**
- **File splitting** for email/network transfer

### 4. **Archive Support**
- Built-in support for ZIP, RAR, 7Z, TAR, GZIP, CAB, ACE, ARJ, LHA, JAR, ISO
- Virtual file system for archives (browse like folders)
- Multi-volume archives
- Password-protected archives
- Self-extracting archives

### 5. **File Viewing/Editing**
- Built-in viewers for 300+ file formats
- **Lister** with syntax highlighting
- **Hex editor** with binary/hex/ASCII views
- **Image viewer** with thumbnail support
- **Multi-tab viewer** for multiple files
- **Quick view panel** (F3)

### 6. **Search & Find**
- **Multi-criteria search** (name, content, date, size)
- **Regular expression** support
- **Search in archives**
- **Plugins for content search** (text, binary, Office files)
- **Duplicate file finder**
- **Advanced file comparison**

### 7. **FTP/Network Support**
- Built-in FTP client with resume support
- SFTP (SSH) support
- WebDAV, WebDAV, Amazon S3, Google Drive, Dropbox
- **Background transfers** with queue
- **Synchronize directories** with preview
- **Connection manager** for multiple servers

### 8. **File Synchronization**

- **Synchronize timestamps** and attributes
